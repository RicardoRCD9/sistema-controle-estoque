# Sistema de Controle de Estoque

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema de controle de estoque utilizando Python, como parte das atividades práticas do curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é aplicar conceitos de lógica de programação e desenvolver uma aplicação capaz de gerenciar produtos de um estoque.

## Funcionalidades

- Cadastro de produtos.
- Validação de dados informados pelo usuário.
- Verificação de códigos de produtos.
- Consulta e gerenciamento das informações do estoque.
- Cálculo de informações relacionadas ao estoque.

*Observação: a lista de funcionalidades deverá ser ajustada conforme os recursos efetivamente implementados no código.*

## Tecnologias utilizadas

- Python 3

## Como executar

1. Instale o Python em seu computador.
2. Faça o download ou clone deste repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o arquivo Python:

```bash
python "PTI Desenvolvimento de um Sistema de Controle de Estoque.py"
```

## Objetivo educacional

Projeto desenvolvido para praticar lógica de programação, estruturas de dados, funções, estruturas de repetição e validação de entradas em Python.
